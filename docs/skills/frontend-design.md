# Skill: Frontend Design

Use this skill for distinctive, production-grade frontend UI: pages, components, landing pages, dashboards, portals, forms, and visual polish.

## Goals

- Avoid generic AI-looking designs.
- Choose a clear aesthetic direction based on the client, audience, and offer.
- Make layout, type, spacing, color, and imagery feel intentional.
- Keep accessibility and responsive behavior built in from the start.

## Process

1. Read `docs/project/PROJECT_BRIEF.md`, `CLIENT_INTAKE.md`, and `WEBSITE_SCOPE.md`.
2. Identify the audience, desired emotion, and primary conversion action.
3. Choose a visual direction in plain language before implementing.
4. Design mobile-first, then scale up.
5. Use realistic copy and content lengths.
6. Verify contrast, keyboard access, focus states, loading states, error states, and empty states.

## Avoid

- Default purple/blue gradients without brand reason.
- Identical card grids for every section.
- Oversized spacing that weakens hierarchy.
- Decorative motion that distracts or harms accessibility.
- Placeholder copy that hides real content problems.

## Verification Checklist

- [ ] Visual direction fits the client/business context.
- [ ] Primary CTA is clear.
- [ ] Typography hierarchy is readable.
- [ ] Spacing is consistent.
- [ ] Mobile and desktop layouts work.
- [ ] Accessibility basics are covered.
- [ ] Design does not look like a generic template.
