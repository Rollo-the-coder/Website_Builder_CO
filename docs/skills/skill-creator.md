# Skill: Skill Creator

Use this only when a repeated workflow appears at least 2-3 times or when the user explicitly wants a new reusable skill.

## Process

1. Define intent: what recurring task the skill improves.
2. Define trigger conditions: when the skill should and should not be used.
3. Draft the skill in concise Markdown.
4. Add examples that show correct usage.
5. Add a verification checklist.
6. Test with sample prompts.
7. Iterate based on misses, false triggers, or confusing instructions.

## Skill Template

```markdown
# Skill: [Name]

## Use When

[Trigger conditions]

## Do Not Use When

[Boundaries]

## Process

[Steps]

## Examples

[Good examples]

## Verification

[Checklist]
```

## Rules

- Keep skills focused and short.
- Prefer project-specific context over generic advice.
- Preserve attribution for adapted external content.
- Do not add secrets, account IDs, or private client details.
