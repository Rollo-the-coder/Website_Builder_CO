## On-Page Basics

- [ ] Unique page titles
- [ ] Meta descriptions
- [ ] One clear H1 per page
- [ ] Logical H2/H3 structure
- [ ] Internal links between related pages
- [ ] Image alt text

## Local Signals

- [ ] Google Business Profile notes
- [ ] NAP consistency: name, address, phone
- [ ] Service area consistency
- [ ] Local testimonials or proof
- [ ] Location-specific copy where appropriate
- [ ] Embedded map if useful

## Schema Ideas

- [ ] LocalBusiness
- [ ] Service
- [ ] FAQPage
- [ ] Review or AggregateRating if compliant and accurate
- [ ] BreadcrumbList

## Trust Signals

- [ ] Licenses/certifications
- [ ] Insurance/bonding if relevant
- [ ] Awards
- [ ] Associations
- [ ] Real project photos
- [ ] Clear contact information
