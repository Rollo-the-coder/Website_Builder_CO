# Launch Checklist

## Device And Browser Checks

- [ ] Mobile check
- [ ] Desktop check
- [ ] Major browser check
- [ ] Responsive breakpoints reviewed

## Functionality

- [ ] Forms tested
- [ ] Form notifications confirmed
- [ ] Links tested
- [ ] Navigation tested
- [ ] 404 page checked
- [ ] Redirects configured and tested

## Quality

- [ ] Console errors checked
- [ ] Performance reviewed
- [ ] Accessibility basics checked
- [ ] SEO basics checked
- [ ] Image alt text reviewed
- [ ] Metadata reviewed

## Tracking And Deployment

- [ ] Analytics installed if required
- [ ] Conversion events tested if required
- [ ] Deployment complete
- [ ] DNS and SSL verified
- [ ] Backup/rollback plan known

## Final Launch Gap Checks

- [ ] Authorization negative tests completed (`AUTHORIZATION_TEST_PLAN.md`)
- [ ] Backup and rollback plan documented (`BACKUP_AND_ROLLBACK_PLAN.md`)
- [ ] Email deliverability verified (`EMAIL_DELIVERABILITY_PLAN.md`)
- [ ] Admin audit logs in place if sensitive app
- [ ] Privacy / minor data review completed if applicable (`PRIVACY_AND_DATA_RETENTION.md`)
- [ ] Timezone / date / money edge cases checked
- [ ] Accessibility and reduced-motion reviewed
- [ ] Browser / device test matrix completed (`BROWSER_DEVICE_TEST_MATRIX.md`)
- [ ] Environment separation verified (dev/staging/prod, test vs live keys)
- [ ] `FINAL_LAUNCH_REVIEW.md` completed

## Approval

- [ ] Client reviewed staging or preview
- [ ] Client approval received
- [ ] Known limitations documented
- [ ] Launch date/time confirmed
