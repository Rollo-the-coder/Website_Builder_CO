# Skill Usage Policy

Skills in `docs/skills/` are local Markdown references committed to this repo. They are portable, reviewed, and require no npm install for Cursor usage.

Use local skills only when a task benefits from specialized guidance. Project-specific context in `docs/project/` takes priority over generic skill advice.

The `npx skills add` ecosystem can be used later in a specific project to fetch or update external skills, but this starter relies on local Markdown docs for portability and reviewability.

Do not add external skills blindly. Review them for relevance, safety, licensing, attribution, and project fit before committing adapted content.
