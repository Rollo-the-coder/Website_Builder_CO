# Agent Run Log

This optional file tracks work when the agent-loop workflow is intentionally adopted. It is not active by default.

## Log Format

```md
## YYYY-MM-DD HH:MM - Short Title

### Task
What was attempted.

### Files Changed
- path/to/file

### Validation
- Command: `command here`
- Result: Passed/Failed/Not run
- Notes:

### Status
Complete / Partial / Blocked

### Next Step
What should happen next.
```
